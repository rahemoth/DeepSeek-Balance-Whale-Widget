Windows 桌面移植 fork 更新。本仓库基于 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)，不是上游官方 Windows 发行版。

下载 `WhaleWidget-Setup-1.0.2-Windows-x64.exe`。已安装 1.0.0 或 1.0.1 的用户可直接运行新版安装包覆盖升级，无需先卸载；保留原安装目录、密钥、账目、角色、泡泡和布局。建议升级前从托盘退出小肥鱼。支持 Windows x64，未配置代码签名。

- Windows 透明挂件窗口改用软件渲染，并禁用被遮挡窗口的后台降速，提高后台运行的稳定性。
- 同时检测脚本心跳与动画帧；脚本还在运行、画面已停止推进时，也能触发自动恢复。
- 鼠标进入可交互区域时恢复窗口可聚焦状态，再关闭穿透，并定期重新应用可交互状态，减少角色点不动的问题。
- 延续 v1.0.1 的 Plus 冷启动读取、系统代理超时、配置保留和恢复频率限制。正常等待余额不会触发界面重载。

自动恢复的记录位于 `%APPDATA%\WhaleWidget\data\desktop-health.log`，仅记录事件及时间。已验证模拟脚本卡死、动画帧停止时的恢复与配置保留；本机实际使用也已确认恢复正常，但偶发卡住的原始触发原因仍需继续观察。

安装包不包含本机登录态、密钥或个人配置；程序内保留上游许可和来源说明。附带 `SHA256SUMS.txt` 校验文件。

发布验证：22 项测试通过；实际运行 1.0.1 → 1.0.2 安装升级，自动沿用原安装目录，13 个配置及界面状态文件校验一致。升级后的安装版通过真实 Electron 界面检查、两次 Plus 冷启动读取，以及脚本卡死和动画帧停止的自动恢复、配置保留检查。打包后的修复文件与源码一致，未包含个人配置或凭据。
