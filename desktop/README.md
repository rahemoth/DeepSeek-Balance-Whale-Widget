# 小鲸鱼 Windows 桌面版

本目录是 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 的 fork，提供独立 Windows 桌面版本。使用 Electron 运行原项目的完整 `assets/whale-widget.js` 与 `lib/index.js`，保留上游作者、代码许可与素材来源说明。

## 运行

安装版：在本 fork 的 GitHub Releases 下载 `WhaleWidget-Setup-*-Windows-x64.exe`，按向导选择目录安装。安装器提供桌面和开始菜单快捷方式。应用数据仍存放在 `%APPDATA%\WhaleWidget`，卸载不会删除这些数据。此版本未配置代码签名。

已安装依赖时双击 `start.cmd`。也可以在本目录执行 `npm start`。首次设置面板可以填写 DeepSeek API Key；留空也能使用角色、泡泡和本地数据功能。

新机器首次安装：Node.js 22 或更新版本，执行 `npm ci`，再执行 `npm start`。Electron 初次安装需要下载其 Windows 运行时。

鼠标移到角色旁点击 ☰ 打开原版菜单。按住角色拖动，贴边吸附与镜像、角色大小、泡泡队列、模块库、泡泡框、图片动图、随机内容、字体样式、角色导入、音频片段与音效组、余额提醒、预算、余额校正、自定义厂商和多窗口额度均使用原版功能。

托盘右键可显示/隐藏、打开桌面设置、移动到另一显示器、重置位置、打开数据目录或退出。`Ctrl+Alt+W` 切换显示/隐藏。桌面设置可选择置顶与登录 Windows 时启动。

窗口覆盖所选显示器的工作区，透明区域会穿透鼠标；设置弹窗开启时其遮罩接收鼠标。角色图使用原版 alpha 命中判断。显示器、分辨率、任务栏工作区变化和系统唤醒后会重新定位。

## 配置与旧版迁移

角色上方增加旧桌面版样式的常驻卡片，底部按钮切换 DeepSeek / OpenCode Go / ChatGPT。DeepSeek 显示总余额、充值与赠金；OpenCode Go 显示 5h / 周 / 月剩余与已用百分比；ChatGPT 显示实际套餐（例如 Pro）、订阅剩余天数（有字段才显示）、5h / 周剩余额度与重置时间。ChatGPT 的百分比是 Codex 额度，不是金额余额。未知额度显示 `—`。卡片每 15 秒刷新，也可点击右上角刷新；GPT 窗口取数失败只缓存 5 秒，成功缓存 15 秒。

余额／套餐气泡沿用原版 5 秒自动收起；后台刷新只更新仍在显示的内容，不续时、不重新弹出。点余额气泡进入趣味文案／动图的功能保留。

“小肥鱼记账 → 显示项目”分别勾选卡片与泡泡的来源。卡片底部只显示勾选来源的按钮，始终单项显示；点鱼泡泡按 DS → OCG → GPT 循环，每次只显示一个来源。套餐泡泡只显示 5h 的原版简洁已用百分比与重置字样，不显示周／月或滚动条；完整窗口仍在卡片和设置中查看。点余额泡泡进入原版后续趣味文案／动图序列，再点按原序列推进或收起。没有勾选泡泡来源时使用原自定义队列。已有自定义队列不会被改写。

同一区域可切换详细／原项目迷你样式、跟随鱼／固定桌面位置、50%–150% 大小并恢复默认位置。卡片内文字、按钮与间距随尺寸一起缩放。拖动卡片标题栏调整位置。卡片会临时避让角色、打开的泡泡与菜单，空间不足时隐藏，关闭泡泡后恢复；避让不会覆盖保存位置。布局重启后保留。

GPT／OCG 的设置精简为连接设置、剩余额度预警、额度使用提醒。阈值为 0–100%，按选中的额度窗口判断；默认 5h、预警剩余 20%、使用提醒已用 80%，默认关闭。旧金额规则停用并作为旧记录保留，须重新配置百分比阈值。同规则同窗口周期提醒一次，窗口重置后重新允许提醒；未知数据不会触发。

托盘 → 桌面设置填写 DeepSeek 和 OpenCode Go Key。ChatGPT 使用本机 Codex 登录态，无须再填密钥。两种订阅来源首次启动自动加入原版记账模型列表；已有同厂商配置会复用。

ChatGPT 额度读取进程自动使用 Windows 系统代理（含 PAC）；已有代理环境变量优先。代理只传给读取进程，不修改系统设置。自定义 Codex 登录路径也会用于实际额度请求。网络失败、超时和登录失效会在卡片中显示原因，并按刷新周期重试。

新数据位于 `%APPDATA%\WhaleWidget\data`，与 DSH 和旧 Python 桌面版分开保存。图片和音频资源也位于此目录，更新源码不会删除数据。界面位置和偏好由固定的 `whale://app` 源保存，不会随随机端口变化丢失。

密钥通过 Electron `safeStorage` 使用 Windows DPAPI 加密，保存在 `credentials.enc.json`；环境变量仍优先。删除环境变量密钥需要修改启动环境。DPAPI 保护不同 Windows 用户之间的访问，不隔离同一 Windows 用户运行的程序。

托盘 → 桌面设置 → 导入旧桌面版 `config.json`：导入 DeepSeek、OpenCode Go 密钥与显示项目，并创建对应的 ChatGPT 套餐、OpenCode Go 模型；原文件保留。已有新配置会先备份到 `migration-backups`。旧版刷新间隔未导入，新版沿用原项目刷新策略。

## 会话相关功能的边界

独立桌面进程没有 DSH 的 `session/event` 来源，DSH 账号登录服务也不在其中。因此 DSH 提问、授权、逐轮结束提示、DSH 当前对话名和本机会话费用不会自动接通；保留的原版配置及宿主事件处理逻辑供后续会话连接使用。DeepSeek 余额观测记账可独立工作。Codex 本地统计与 ChatGPT 套餐使用原项目已有的本地日志与 app-server 读取逻辑，需要本机实际有对应数据/程序；不能把估算费用当作官方扣费。

## 验证

`npm test` 检查全部 26 个原版接口、来源限制、资源读取、配置保存、余额变动记账、事件处理、凭据并发和旧配置迁移。网络余额使用模拟响应，不调用真实付费服务。

`npm run test:ui` 在真实 Windows Electron 窗口中检查菜单、泡泡编辑器、音效面板、资源管理、角色拖拽与位置持久化、透明区命中和 Windows 加密；截图保存到 `test-results`。测试使用临时数据目录。

设置 `WHALE_TEST_EXECUTABLE` 为安装后 `Whale Widget.exe` 的绝对路径，可用相同界面测试验证安装版。Windows 桌面 v1.0.0 已通过实际 NSIS 安装与安装后的界面测试。

`node tests/plus-startup.mjs` 是手动运行的真实登录测试：用临时挂件数据连续冷启动两次，检查本机 ChatGPT 登录的 5h／周窗口读取；不打印凭据或具体额度。本机 Plus 已通过此测试。

未进行真实 API Key 连通性、多显示器硬件切换或实际鼠标点击底层应用的人工验证。

资源许可与来源仍遵循仓库 `LICENSE` 与 `PROVENANCE.md`。执行 `npm ci` 后运行 `npm run build` 构建 Windows x64 NSIS 安装器，输出到 `dist`；构建不会自动发布。
